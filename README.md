# 🚀 30 Days of Python Projects (From Basics to Backend)

Welcome to my 30-day Python project challenge! I took a break from Python and created this roadmap to rebuild my muscle memory and level up my skills from absolute basics to intermediate backend development.

## 🎯 The Goal
To build one functional Python project every day for 30 days, escaping "tutorial hell" and focusing on real-world application. 

### 🛠️ Tech Stack Covered:
- **Core Python:** CLI tools, File I/O, OOP, JSON
- **Web & APIs:** `requests`, `BeautifulSoup` (Scraping)
- **Databases:** `sqlite3` 
- **Backend Framework:** FastAPI, Pydantic
