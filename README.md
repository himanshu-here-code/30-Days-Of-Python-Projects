## 📖 Welcome!

After taking a break from Python, I created this **30-day challenge** to rebuild muscle memory and level up from fundamentals to real backend development. Each day brings a new, functional project—not tutorials, but **real-world applications**.

**The mission?** Escape tutorial hell and ship working code every single day.

---

## 🎯 What You'll Build

- ✅ **Days 1-7**: Powerful CLI tools with real user interaction
- ✅ **Days 8-14**: Web scrapers and API integrations  
- ✅ **Days 15-21**: Database-driven applications with SQL
- ✅ **Days 22-30**: A complete production-ready backend API

## 📅 The 30-Day Roadmap

### 🔰 Phase 1: Muscle Memory *(Days 1-7)*
**Building Blocks** — Master syntax, loops, functions, and file handling with real CLI applications.

| Day | 📌 Project | Concepts |
|:---:|---|---|
| **1** | CLI BMI Calculator & Triangle Validator | Input validation, conditionals |
| **2** | Bulk File Renamer | File I/O, `os` module, string manipulation |
| **3** | Text Analyzer & Word Counter | Text processing, dictionaries, `collections` |
| **4** | CLI Contact Book (In-Memory) | Data structures, CRUD operations |
| **5** | Contact Book with JSON Persistence | JSON serialization, file handling |
| **6** | Advanced Random Password Generator | String operations, randomization, security basics |
| **7** | Pomodoro Timer CLI | Time handling, user interaction, state management |

**Checkpoint:** You can build functional CLI tools with proper data handling.

---

### 🌐 Phase 2: Interacting with the Web *(Days 8-14)*
**Web Warrior** — Fetch data from APIs and scrape websites with confidence.

| Day | 🌍 Project | Concepts |
|:---:|---|---|
| **8** | GitHub User Fetcher | REST APIs, `requests` library, JSON parsing |
| **9** | Weather Dashboard | API integration, data formatting, error handling |
| **10** | Hacker News Top 10 | Web scraping, `BeautifulSoup`, HTML parsing |
| **11** | E-commerce Price Checker | Advanced scraping, price monitoring |
| **12** | Crypto Portfolio Tracker | Real-time APIs, financial data handling |
| **13** | Random Joke Generator | API consumption, text formatting |
| **14** | Automated Email Sender | `smtplib`, email automation, user workflows |

**Checkpoint:** You can integrate third-party APIs and scrape the web responsibly.

---

### 🗄️ Phase 3: Data Management *(Days 15-21)*
**Data Master** — Organize and query data like a professional with databases.

| Day | 💾 Project | Concepts |
|:---:|---|---|

| **18** | Secure Password Manager | Data encryption, secure storage, best practices |
| **19** | API to Database Logger | Combining APIs with databases, data pipelines |
| **20** | Job Board Scraper to DB | Web scraping → database persistence |

**Checkpoint:** You can design schemas, write efficient SQL, and manage data professionally.

### ⚡ Phase 4: Building the Backend *(Days 22-30)*
**API Architect** — Create production-ready REST APIs that others can use.

**Checkpoint:** You've built a production-ready API from scratch.

## 🚦 Getting Started

### Prerequisites
- Python 3.8 or higher
- Git and GitHub account
- A code editor (VS Code, PyCharm, etc.)
- ~1-2 hours per day for 30 days

### Quick Setup
```bash
# Clone this repository
git clone https://github.com/himanshu-here-code/30-Days-Python-Projects.git
cd 30-Days-Python-Projects

# Install dependencies (as needed per phase)
pip install requests beautifulsoup4 fastapi uvicorn pydantic
```
